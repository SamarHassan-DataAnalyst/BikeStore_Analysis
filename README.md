# 🚴BikeStore_Analysis using Excel 
## 📌 Project Overview
 This project analyzes bike sales data across multiple countries, states, and customer demographics.   The dataset includes detailed information about sales transactions such as product type, color, unit cost, unit price, profit margins, and customer attributes.  
The goal of this project is to provide insights into:
- Customer demographics (age, gender, location)
- Product performance (sub-category, color, unit economics)
- Sales trends over time
- Profitability and margin analysis

## 📂 Dataset Description
The dataset is structured with the following key columns:

| Column Name       | Description |
|-------------------|-------------|
| Date              | Date of the sales transaction |
| Customer_Age      | Age of the customer at purchase |
| Customer_Gender   | Gender of the customer |
| Country           | Country of the sale |
| State             | State/Region of the sale |
| Sub_Category      | Product sub-category (e.g., Road Bikes, Mountain Bikes) |
| Bike_Color        | Color of the bike |
| Product           | Product name and size |
| Order_Quantity    | Number of units sold in the transaction |
| Unit_Cost         | Cost per unit to the company |
| Unit_Price        | Selling price per unit |
| Total Orders      | Number of orders in the dataset |
| Total Price       | Total revenue generated |
| Total Cost        | Total cost incurred |
| Total Profit      | Profit from the transaction |
| Margin Profit %   | Profit margin percentage |
| Months            | Month of the transaction |

---

## 📊 Key Insights
- **Top Selling Categories**: Road Bikes dominate sales across most regions.
- **Customer Demographics**: Majority of customers are between ages 17–29.
- **Regional Trends**: Strong sales in Australia, United States, France, Germany, and the UK.
- **Profitability**: Average profit margin ranges between 30–40% depending on product type.
- **Seasonality**: Sales peak in November and December, indicating holiday demand.

## 📈 Analysis Workflow
1. **Data Cleaning**  
   - Handle missing values  
   - Standardize column names  
   - Convert dates to proper formats  

2. **Exploratory Data Analysis (EDA)**  
   - Customer demographics distribution  
   - Product category performance  
   - Regional sales comparison  

3. **Profitability Analysis**  
   - Calculate total revenue, cost, and profit  
   - Compute margin percentages
   - Average Order price
   - Average Quantity of items per Order
   - Identify high-margin products  

4. **Visualization**  
   - Sales trends by month  
   - Profitability by product category  
   - Customer age vs. purchase behavior
   - Age Bins (Age range) with the highest orders or Average age of Customer
   - Max order Quantity / order Price
     
---
5. **🖥️ Dashboard & Business Intelligence**
The accompanying Excel workbook is structured into multiple functional sheets designed for stakeholder reporting:

- Sales Data: Cleaned, transaction-level master data table.

- Pivot Table: Summarized data aggregations slicing profitability by region, product category, and customer segments.

- Dashboard: Interactive executive summary layout featuring dynamic KPIs, visual charts, and slicers to filter performance dynamically.
